Groundtruth

A retrieval evaluation harness for a legal research assistant: 100 questions over 510 real contracts, each answered by a passage lawyers labelled. The recommended configuration puts that passage in the top 10 for 70.0% of questions, against 36.8% for plain BM25, and CI fails any change that costs more than a point.

The gate

  • Every push reruns the recommended configuration on all 100 questions and fails if recall@10 drops more than 1 point below results/baseline.json.
  • The branch demo/smaller-chunks shrinks chunks to 128 words, a change that sounds harmless. Recall@10 falls from 70.0 to 49.8 and CI goes red.
  • The golden set has 100 questions, so one question is one point. The tolerance is set at that, not below it.
